# 製品要件のフレームワーク: 倒立振子ロボット

## このフレームワークの概要
このフレームワークでは、ペルソナを仮定し、そのペルソナがシステムをどのようなユースケースで使用し、システムは稼働開始から終了までどのように振る舞うのかをイメージする。

## ペルソナ定義 (Who)
* 自己研鑽として、倒立振子を開発する組込みソフトエンジニア
* 30歳
* 組込みSW開発歴は1.5年、PLC制御システム開発歴は5年
* 賃貸アパート住み
* 一人暮らし
* 年収は平均よりも高い

## ユースケース
### システム起動の動機 (Why)
* 自分で実装した倒立振子の動きを確認したい
* 会社での成果アピールで披露したい
* この倒立振子をベースに、他にも自己研鑽をしたい

### システムを動かす場所 (Where)
* 賃貸アパートのフローリング (スペースは横2m、縦1m程度)
* 会社の会議机　(スペースは横1m、縦50cm程度)

### 稼働開始から終了までどのように振る舞うか (How)
* 稼働開始
* 過渡期
* 安定期
* 崩壊期
* 稼働終了

``` mermaid
graph TD
稼働開始[倒立状態からx度まで傾けた状態で電源ON] --> 過渡期[倒立状態になるように調整]
過渡期[倒立状態になるように調整] --> 安定期[倒立状態を保持]
過渡期[倒立状態になるように調整] --> 崩壊期[倒立振子が倒れてしまう]
過渡期[倒立状態になるように調整] --> 稼働終了[倒立振子を持ち上げて電源OFF]
安定期[倒立状態を保持] --> 稼働終了[倒立振子を持ち上げて電源OFF]
崩壊期[倒立振子が倒れてしまう] --> 稼働終了[倒立振子を持ち上げて電源OFF]
```

##　倒立振子は製品として何を叶えるのか (KGI)
* 安定期を15秒間継続すること。
